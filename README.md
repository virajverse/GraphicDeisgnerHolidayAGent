## 🌟 Key Features

### 1. 🧠 27-Model NVIDIA NIM AI Cluster Cascade
- Built-in multi-pool failover routing across 27 high-speed LLM models (`nemotron-3-nano`, `llama-3.1-8b`, `qwen2.5-coder`, `mistral-nemo`, `deepseek-r1`, etc.).
- 100% resilient zero-downtime inference with automatic cascade jumping if any model encounters rate-limits or timeouts.

### 2. 🛡️ Military-Grade Database Security Shield
- **Zero-Trust Parameter Inspection:** Heuristically analyzes and blocks SQL Injection payloads (`UNION SELECT`, `' OR 1=1`, `DROP TABLE`).
- **Destructive DDL Lockdown:** Blocks unauthorized schema alterations.
- **Resource Exhaustion Guard:** Built-in rate limiter (max 200 queries/10s).
- **Secret Redaction:** Auto-masks Telegram bot tokens, API keys, and sensitive credentials in logs.
- **Turso Cloud SQLite:** In-memory synchronous fast cache with asynchronous persistent write-through to AWS Mumbai LibSQL.

### 3. 🎨 Visual Media & Color Harmony Engine
- **Visual Hex Swatch Cards:** Renders actual colored unicode blocks (`🔴`, `🟠`, `🟡`, `🟢`, `🔵`, `🟣`, `⚫`, `⚪`) alongside 1080x1350 canvas layouts.
- **Dynamic Animated GIFs:** Automated celebratory animations on VIP onboarding, referral rewards, and visual specs requests.

### 4. 👑 Super Admin & Affiliate Campaign Engine
- **Deep-Link Attribution:** Generates named promotional affiliate links (`https://t.me/GraphicDeisgnerHolidayAGent_bot?start=aff_CODE`).
- **Auto VIP Onboarding:** 1-tap auto-approval and custom bonus AI credits for partner audiences.
- **Real-Time Conversion Alerts:** Instant Telegram push notifications sent to Admin on every signup.

### 5. 🎁 4-Tier Designer Referral & Rewards
- Automatic peer-to-peer invite tracking (`/start ref_CHATID`).
- Tier progression with unlocking perks:
  - 🥉 **BRONZE** (1-4 Referrals)
  - 🥈 **SILVER** (5-14 Referrals)
  - 🥇 **GOLD** (15-29 Referrals)
  - 💎 **DIAMOND** (30+ Referrals)

## 🚀 Quick Start

### 1. Clone the Repository
```bash
git clone https://github.com/virajverse/GraphicDeisgnerHolidayAGent.git
cd GraphicDeisgnerHolidayAGent
```

### 2. Install Dependencies
```bash
npm install
```

### 3. Configure Environment Variables
Create a `.env` file based on `.env.example`:
```env
# Telegram Bot
TELEGRAM_BOT_TOKEN=your_telegram_bot_token_here
TELEGRAM_DEFAULT_CHAT_ID=your_chat_id_here
TELEGRAM_BOT_USERNAME=your_bot_username

# NVIDIA NIM Cluster
NVIDIA_NIM_API_KEY=nvapi-your_api_key_here

# Turso Cloud Database
TURSO_DATABASE_URL=libsql://your-db-name.turso.io
TURSO_AUTH_TOKEN=your_turso_auth_token_here

# Admin Settings
ADMIN_INVITE_CODE=YOUR_ADMIN_SECRET_CODE
ADMIN_TELEGRAM_HANDLE=@your_admin_handle
PORT=3000
```

### 4. Build & Run
```bash
# Compile TypeScript
npm run build

# Start Local Server
npm start

# Run in Development Mode
npm run dev
```
